# Device clients — E03/E04

The user owns iPhone/Mac setup. Obsidian remains the offline editor; encrypted LiveSync compatibility and plaintext bridge trust must be proven using disposable notes in CAL-009 before valuable notes are added.

CAL-014/CAL-015 provide user-executable install/capture/rollback steps, typed/dictated timing tests and visible offline failure behavior. Online capture uses a registered device grant and the [capture contract](../contracts/capture.yaml). Online retries and offline fallback retain the same capture UUID; data owns reconciliation. Never send a sync password as a capture API credential. No Shortcut or client installation is delivered by E01. See [release scope](../docs/release-scope.md).
